## First animation

1. Click **Try demo**, or **Import image** to choose a PNG or JPG.
2. Pause, select a region, and **Paint** the part you want to move. Use **Erase**, brush size, and hardness to refine it. Under **Mask visibility**, choose that region's own color or a bright preset, adjust overlay opacity, and enable the black/white outline. **Selected mask only** switches between the selected mask and all masks. These settings affect only the overlay, never image pixels or motion weights. Outlines follow painted edges; motion softness can extend beyond those edges.
3. Use **Anchor** to paint stationary attachment areas, shown in blue. Anchors protect the image from every motion region. **Unpin** removes anchor paint.
4. Select a preset, direction, amplitude, speed, softness, and phase. Add more regions with **+**. Each region has independent settings and can be disabled. Hair sway holds roots and bends more strongly toward delayed tips. Roots follow anchors within the mask, or the mask's upper edge when there are no anchors. Use **Hair root · R** and click/drag on the image to choose a root for the selected region; it snaps to the nearest mask vertex. **Use automatic hair roots** clears that override. Paint blue anchors to keep attachment areas fixed against every overlapping region.
5. Press **Play**. Pause freezes the current pose. Reset returns to the undeformed image at time zero. Motion-mask painting returns to time zero. Blink mask painting can retain any closure: lash strokes map back to the original lash texture, while limit/protection strokes stay fixed in artwork space. The mask overlay is hidden during playback. **Original** temporarily displays the undeformed source for comparison.
6. **Save project** downloads a `.stillwave` file. Use **Open project** to restore it. The file includes the source image, every painted mask, anchors, region names, motion settings, custom roots, region colors, opacity, outline, mask visibility and selected-only/all-mask preference. Save manually; there is no automatic recovery. Older version-1 projects still open and receive sensible display defaults. Old version-1 projects still load. New paths, extracted patches and backing repairs use version 2; older Stillwave builds cannot reopen these new features.

Wheel to zoom around the pointer. Middle-drag, Pan tool, or Space + drag pans. Space alone toggles playback. B/E/A/U/H/R select paint/erase/anchor/unpin/pan/hair-root. Ctrl+Z undoes; Ctrl+Shift+Z redoes. Brush sizes, softness, and amplitude use original image pixels. Direction 0° is right, 90° is down. Speed is cycles per second. Open **hair-study.stillwave** for two individually masked fringe locks on the recorded illustration, with independent timing and held roots.

## Rendering approach

A continuous regular triangular mesh samples the original full-resolution texture using WebGL bilinear filtering. Its longest dimension has 144 cells (the supplied 720 × 956 illustration uses 15,805 vertices / 31,104 triangles). Texture coordinates stay fixed while source-space vertices deform. Shared vertices prevent cracks between regions. This remains the default flat-mask workflow. Optional extracted artwork uses separate cropped textured meshes with a matching source holdout and backing repair surface; see the studio guide.

Painted masks use a canvas with at most 512 pixels on its longest side. A Gaussian blur controls edge softness; bilinear sampling and cubic smoothstep convert mask alpha into smooth per-vertex influence. Sway uses connected-mask root distances, a stable-base bending envelope, phase lag and a small tip harmonic. Breathing expands around the mask's weighted center; bounce combines two harmonics; oscillation uses a sine wave. Overlaps use squared-influence partition weights with smooth union coverage, global anchor coverage suppresses movement, and the image perimeter is pinned.

A local displacement-gradient guard corrects strained grid edges while leaving distant healthy areas alone. A bounded iterative projection enforces gentle deformation. Severe unresolved fields receive a final safety scale restricted to their connected active island. The preview reports the fraction of vertices corrected, not a global amplitude multiplier. The bound keeps triangles from folding; it cannot preserve all local detail under arbitrary stretching. [RESEARCH.md](RESEARCH.md) explains the four GitHub references, compatibility decisions, implemented work, experiments and limits.

Reference for the underlying texture and shader pipeline: [MDN: Using textures in WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Tutorial/Using_textures_in_WebGL). The animation field, painting, project format, and editor are original prototype code.

## Current limits / next improvements

- Flat-mask motion still warps adjacent background pixels. Optional extraction isolates the moving pixels; it requires a manually prepared matte and repaired hidden background. The supplied extraction examples demonstrate the mechanism and still need edge/underpainting refinement.
- No automatic segmentation, layer extraction, genuine hidden-eyelid reconstruction, physics simulation, timeline keyframes, general video export, or native desktop packaging. Up to two eyes support shared automatic timing, independent curves/lashes/crease/repair/masks and skin touch-ups. Automatic isolation still needs correction; corners, skin seams and high-roll thinning remain limitations. The crease uses a local warp, not a physical folding lid. Independent eye clocks remain future work. The four motion presets remain implemented deformations.
- The fixed grid and 512px masks can miss very small features. Adaptive mesh density and higher resolution masks would improve eyes and fine strands. Mask softness deliberately influences nearby pixels outside the raw painted edge.
- Strong narrow masks and sharp anchors can still reduce motion locally. A severe unresolved field can damp its whole connected active island, including touching/overlapping regions, while separate islands retain their strength. This is a kinematic deformation prototype, not a physical strand solver. Automatic top-edge roots may need manual placement for sideways/upward hair.
- Maximum 24 regions, 40 MB imported image file, 32 megapixels total, and 8192 pixels per side (or the GPU's lower texture limit). Larger artwork must be resized first. Project files are limited to 100 MB. Alpha PNGs and JPGs with backgrounds are supported.
- Undo history is bounded by region count, motion-mask memory and eye-raster data. View position, preview time, and history are not saved. Project saving uses the browser's download location; reopening uses an explicit file picker.
